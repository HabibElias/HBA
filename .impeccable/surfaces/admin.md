# Staff content workspace

Mode: Operate.

The user requested content management inside the existing Next.js project and confirmed Owner, Administrator, Editor, and Viewer roles. The visual system inherits the church purple accent and Plus Jakarta Sans. This surface is a task workspace: a persistent navigation sidebar, content lists, bilingual forms, a publishing panel, and a permission matrix. On narrow screens navigation expands inline and wide data tables scroll within their own region.

The first screen gives direct access to real content and drafts needing review. It does not invent traffic statistics. Keep controls compact, state labels explicit, and publishing/access changes reviewable. No decorative cutouts or entrance animations on operational controls.
