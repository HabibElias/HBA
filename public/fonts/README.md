# Brand fonts

Self-hosted variable WOFF2 subsets from Google Fonts, downloaded 2026-10-21. Family names, weights and Unicode ranges are preserved in app/fonts.css. Latin is included for all five families; Ethiopic is included for both Noto families. This removes Google network access from both builds and visits.

Source: https://fonts.google.com/

Each family is distributed under the SIL Open Font License 1.1; its license is stored beside the font files.
